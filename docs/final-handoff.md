# Project Pulse final handoff

Mona's Project Pulse dashboard is built and committed. It was orchestrated with GitHub Copilot CLI in a Codespace using four custom agents defined in `.github/agents/`.

## Agent team

| Agent | Model | Role in this build |
| --- | --- | --- |
| Orchestrator | Claude Opus 5.5 | Coordinated the phases and file scopes. |
| Planner | Claude Opus 5.5 | Produced `docs/project-pulse-plan.md`. |
| Designer | Gemini 3.7 Flash | Wrote `app/styles.css` (layout, badges, priority, accessibility). |
| Coder | GPT-5.5 | Wrote `app/project-data.json`, `app/index.html` and `.vscode/launch.json`. |

## Deliverables

- `app/index.html`: title "Project Pulse"; links `styles.css`; fetches `project-data.json`; renders one `project-card` per project showing status, `recentActivity` and priority. Handles fetch errors, an empty list, missing fields and `file://` access.
- `app/styles.css`: `.dashboard` and `.project-card` selectors, `border-radius`, `box-shadow`, responsive grid with `@media` breakpoints, status and priority styling, focus and reduced-motion support.
- `app/project-data.json`: top-level `"projects"` array of 6 projects, each with `name`, `owner`, `status`, `recentActivity` and `priority`.
- `.vscode/launch.json`: strict JSON with the launch name "Run Project Pulse Dashboard". It runs `python3 -m http.server 5500` from `${workspaceFolder}/app` and opens `http://localhost:%s/index.html` through `serverReadyAction`.

## How to run

1. Open Run and Debug in VS Code.
1. Choose "Run Project Pulse Dashboard" and start it.
1. The dashboard opens at `index.html` on port 5500, not as a directory listing.

## Validation results

Checked automatically:

- `app/project-data.json` and `.vscode/launch.json` parse as valid JSON.
- All 6 projects have the five required fields. Statuses used: On track (2), At risk (2), Blocked (1), Done (1). Priorities used: High (2), Medium (2), Low (2).
- `app/index.html` contains `<title>Project Pulse</title>`, and its inline script passes a JavaScript syntax check.
- `app/styles.css` contains `.dashboard`, `.project-card`, `border-radius`, `box-shadow` and `@media`.
- A temporary local server returned HTTP 200 for `index.html`, `styles.css` and `project-data.json`.
- The class names generated by the script (`status-<slug>`, `priority-<slug>`, `project-card`) match the contract in `docs/project-pulse-plan.md`.

Not verified:

- The page was not opened in a browser, so rendering, colour contrast ratios and the 375px layout are unchecked.
- The "Run Project Pulse Dashboard" configuration was not run from VS Code, so port 5500 and the `serverReadyAction` pattern are untested.

## Known issues and follow-ups

- `app/styles.css` styles error messages through `.error` and `data-state="error"`, but `app/index.html` never sets either, so errors show with default notice styling.
- `.status-unknown` and `.priority-unknown` are styled but are outside the original shared contract.
- If port 5500 is already in use, the server will fail to start; stop the other process or change the port.
